NEXT / COMPARISON PROTOCOL

One task set.
The same scoring rules.

Use a versioned unseen dataset, identical evidence and tool access, fixed generation settings where comparable, repeated trials and blinded human review. Log exact model IDs, access dates, prompts, tokens, failures and latency.

What earns a recommendation

Evidence support, task success, valid structure, appropriate abstention and tool-use correctness. Report quality next to successful-task latency and actual billed cost. Keep provider evaluations separate from the synthetic telemetry replay.

Recheck availability, pricing and version status before a live run. No API credentials are requested or embedded in this page.
