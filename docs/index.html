Find the signal.

Scope a set of product feedback, ask a focused question, and follow every answer back to the record it came from. When the evidence is not there, the workspace says so and explains why.

What runs here

31 synthetic records about a fictional product. Keyword retrieval in your browser. Answers quote records verbatim.

No language model runs on this page. An optional LLM adapter exists for the local server only and has not been validated with a real provider.

What this demonstrates

A scoped investigation workflow, verbatim citations with source navigation, explicit abstention, shared retrieval logic across browser and server, and a reproducible evaluation that reports failures.

What it does not show yet

Validated LLM answers, semantic search, learned topic clustering, or testing with real reviewers. No customer adoption or business results are claimed.
